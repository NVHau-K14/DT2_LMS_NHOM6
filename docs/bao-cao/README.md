# Báo cáo sau mỗi giai đoạn

Mỗi giai đoạn hoàn thành có một file `GD<N>.md` trong thư mục này (ví dụ `GD1.md`, `GD2.md`...), viết theo mẫu `_mau.md`.

| GĐ | Nội dung | Báo cáo |
|---|---|---|
| 1 | Nền móng: git, sln, package, models, khởi tạo DB, seeder | [GD1](GD1.md) |
| 2 | Đăng nhập, phân quyền, layout, đổi mật khẩu, trang lỗi | [GD2](GD2.md) |
| 3 | Pipeline điểm & GPA + kiểm thử 5 ca | [GD3](GD3.md) |
| 4 | CRUD Admin: lớp, sinh viên, giảng viên, môn học | [GD4](GD4.md) |
| 5 | Ghi danh + nhập điểm | [GD5](GD5.md) |
| 6 | Báo cáo học lực, tổng quan, cổng sinh viên | [GD6](GD6.md) |
| 7 | Nhập/Xuất Excel | [GD7](GD7.md) |
| 8 | (Tùy chọn) Hiệu năng + API/Swagger | _chưa có_ |
| 9 | Hoàn thiện, export DB, README, tài liệu | _chưa có_ |

Khi một báo cáo được tạo, thay `_chưa có_` bằng liên kết, ví dụ `[GD1](GD1.md)`.

Các báo cáo này là nguyên liệu cho SRS, slide và phần trả lời khi bảo vệ.
